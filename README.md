## What Is This?

This repository contains four ready-to-use Custom HTML blocks 
for WordPress — designed specifically for independent researchers, 
academic writers, and knowledge creators who want a professional 
web presence without coding expertise.

All blocks work as WordPress Custom HTML blocks or Reusable 
Patterns (Synced ON/OFF as needed).

---

## The 4 Blocks

### 1. Researcher ID Block
Displays your verified researcher identity across all major 
academic platforms — ORCID, Google Scholar, SSRN, Zenodo, 
Academia.edu, LinkedIn, and GitHub — in a clean, 
professional badge layout.

**File:** `researcher-id-block.html`

### 2. Author Card
A complete author biography block with circular photo, 
credentials, three book cards with Amazon links, and 
research profile links. Designed for placement after 
the "My Interpretation" section of each article.

**File:** `author-card.html`

### 3. Newsletter CTA
A premium white-card newsletter signup block with gradient 
accent borders, mailto subscribe link, and trust signals.

**File:** `newsletter-cta.html`

### 4. Audio Block
A bilingual audio narration block with scrolling marquee 
in English and Hindi, powered by ResponsiveVoice. Allows 
readers to listen to articles in their preferred language.

**File:** `audio-block.html`

---

## How to Use

1. Open the HTML file
2. Copy the complete code
3. In WordPress editor → click **+** → **Custom HTML**
4. Paste the code
5. Click **Preview** to verify
6. Save as **Pattern** (Synced ON for blocks used across 
   all articles; Synced OFF for article-specific blocks)
